# Kansen / कानसेन

Ear training app for Hindustani classical music.

<p align="center">
  <img src="design/kansen_icon.svg" width="200" height="200" alt="">
</p>

Students as well as fans of classical music can benefit from having a
well-trained ear that is capable of distinguishing and identifying different
scales, and notes within a given scale.

This app can complement an ear training regimen by playing notes and then
quizzing users to identify them. This can help users develop relative pitch,
which is known to be a learnable skill, even in adulthood.

This is a native Android (kotlin) app, under the permissable MIT licence. Bug
reports and feature requests are welcome. PRs are not.

## Installation

Requires Android 8.0 or newer. The downloadable APK is **debug-signed**, not
unsigned, and is distributed outside Google Play.

1. Download the APK from the
   [latest release](https://github.com/abhijeetbodas2001/kansen/releases/latest).
1. Open the downloaded file. If Android asks for permission, open **Settings**
   and enable **Allow from this source** for the browser or file manager you are
   using. This is usually under **Apps → Special app access → Install unknown
   apps**; wording varies by device.
1. Return to the APK and tap **Install**. If Google Play Protect offers to scan
   the app, allow the scan and follow the result. Keep Play Protect enabled.
